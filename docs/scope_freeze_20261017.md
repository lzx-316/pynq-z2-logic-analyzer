# 第一阶段范围冻结记录

日期：2026-10-17
当前 main 基线：`a632eac`
主持人：队长
适用范围：PYNQ-Z2 四通道逻辑分析仪

## 一、必做范围

1. 4 通道数字信号采集。
2. 采样率固定为 1 MSa/s（50 MHz ÷ 50）。
3. 2048 点环形缓冲。
4. 预触发 256 点、后触发 256 点。
5. 上升沿、下降沿、任意边沿三种触发模式。
6. 内部测试模式作为正式演示输入。
7. PYNQ Overlay 加载，使用配套的 bit 与 hwh。
8. Jupyter Notebook 完成配置、采集、波形显示和 CSV 导出。
9. 保留时序、资源、DRC 报告和板级测试证据。
10. 保留可复现的 Tcl 构建脚本和 Git 提交历史。

## 二、不做范围

1. Pmod 外部传感器和摄像头输入。
2. HDMI 显示。
3. DDR 大容量缓存和 DMA。
4. 100 MHz 采样。
5. HLS、Vitis 和网络协议栈。

## 三、条件性选做

1. Pmod A 外部输入：不作为第一阶段必做项，后续仅在必做项稳定后验证。
2. UART 解码：当前不纳入 MVP。10 月 24 日仅在全部 P0 项稳定通过后决定是否加入；否则取消。
3. 演示视频优化：在主体功能和文档稳定后执行。

## 四、冻结规则

1. 2026 年 10 月 31 日后只修复 bug，不增加新功能，不调整架构。
2. 任何新增功能必须由全队确认，并重新评估对提交时间的影响。
3. 任何测试结论必须附日志、截图或 CSV 证据。
4. `bit`、`hwh`、`XSA`、Notebook 和报告数据必须来自同一版本。

## 五、第一阶段验收条件

1. Testbench 在最新 main 上输出 PASS。
2. 队友B独立运行 Notebook 并导出波形和 CSV。
3. 队长完成可换目录的 Tcl 干净重建。
4. 最新 bit/hwh 可加载，4 通道波形正常，连续采集无死锁。
5. 三人均能解释各自负责的模块。
6. 任务看板、测试记录和站会记录与本记录一致。

## 六、当前决定

- 保持四通道 MVP，不增加 UART。
- 正式演示优先使用内部测试模式。
- 在队友B完成独立 Notebook 复跑、队长完成干净重建和板级验证前，不创建 `v0.2-verified` 标签。
