# PYNQ-Z2 逻辑分析仪 Notebook 使用说明

1. 准备工作：将 PYNQ-Z2 通过网线连接到电脑，确认板卡与电脑处于同一网段。
2. 启动板卡：插入已烧录 PYNQ 镜像的 SD 卡，上电后等待板卡指示灯常亮。
3. 打开浏览器：访问板卡地址 http://192.168.2.99 ，默认用户名和密码均为 xilinx。
4. 上传文件：把仓库中 pynq/logic_analyzer.bit 和 pynq/logic_analyzer.hwh 上传到板卡同一目录。
5. 打开 Notebook：进入 notebooks 目录，双击 logic_analyzer_corrected.ipynb。
6. 加载覆盖层：运行第一个单元格，等待 Overlay 加载完成且无报错信息。
7. 设置采样率：在第二个单元格中修改采样率参数，建议先用 50 MSa/s 进行测试。
8. 设置触发：选择触发通道与触发模式（上升沿 / 下降沿 / 电平）。
9. 采集数据：运行采集单元格，等待采集完成后查看波形图。
10. 保存结果：把波形图导出为 PNG、数据保存为 CSV，用于报告与实验复现。
