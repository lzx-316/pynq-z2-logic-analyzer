# 逻辑分析仪测试计划

1. 测试目标：验证 4 通道逻辑分析仪在 PYNQ-Z2 上的采集、触发与数据回读功能。
2. 测试环境：PYNQ-Z2 开发板、Vivado 2020.2、Python 3.8、Jupyter Notebook。
3. 激励信号：使用板上 GPIO 或函数发生器产生 1 kHz ~ 1 MHz 方波与随机脉冲。
4. 采样率验证：分别在 10 MSa/s、50 MSa/s、100 MSa/s 下采集，核对实际采样间隔与设定值一致。
5. 通道验证：4 个通道逐一单独输入信号，检查通道映射正确且无串扰。
6. 触发模式：验证上升沿、下降沿、电平触发三种模式的触发点位置是否准确。
7. 前置/后置采样：设置不同的 pre-trigger 与 post-trigger 比例，检查触发点前后波形是否完整。
8. 存储深度：验证 1024、4096、16384 采样点下数据完整、无丢点。
9. 异常测试：输入超量程电压与高频噪声，确认系统不死机、数据不错乱。
10. 判定标准：以上各项全部通过，采集波形与输入信号一致，时间误差在 ±1 个采样周期以内。
