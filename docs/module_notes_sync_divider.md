# 2026-10-14 模块讲解记录（队友A）

## 模块一：sample_divider.v（采样分频器）

**1. 这个模块是干什么的？**
它的作用是把板子的高频时钟（50 MHz）降频成我们需要的低频采样时钟（1 MHz），并输出一个脉冲（sample_tick），告诉后面的采集引擎：“该采样了！”

**2. 代码是怎么实现的？**
- 首先，在代码开头用 parameter 定义了三个参数：CLK_HZ = 50_000_000（输入时钟），SAMPLE_HZ = 1_000_000（目标采样率），以及计数器的位宽 CNT_WIDTH = 16。
- 然后用 `localparam` 计算分频系数：DIV_VALUE = CLK_HZ / SAMPLE_HZ = 50。也就是说，每来 50 个时钟周期，才输出一次采样脉冲。
- 核心逻辑是一个由时钟驱动的计数器（时序逻辑）。平时计数器一直加 1，sample_tick 保持低电平。当计数器数到 49（也就是 DIV_VALUE - 1）时，计数器归零，同时 sample_tick 变成 1（发出一个脉冲）。这就实现了 50 分频。

**3. 怎么验证它是对的？**
在 Testbench 里检查两件事：
- 看波形，sample_tick 是不是每隔 50 个 clk 周期就冒出一个高电平？如果是，说明 50 分频正确。
- 看 sample_tick 的高电平是不是只持续 1 个时钟周期？如果一直高着，后面的采集引擎就会一直采样，数据会乱套。

## 模块二：sync_4ch.v（四通道信号同步器）

**1. 这个模块是干什么的？**
它负责把从外部引脚进来的 4 个异步信号，同步到 FPGA 内部的本地时钟域，防止亚稳态导致数据出错。

**2. 代码是怎么实现的？**
- 核心逻辑是“两级触发器打拍”。外部信号进来后，先经过第一级触发器（reg1），再经过第二级触发器（reg2）。这样外部信号就和本地时钟对齐了，不会出现亚稳态。
- 为什么必须打两拍？因为外部信号什么时候来是不确定的，如果直接拿去做逻辑，可能会产生随机错误。打两拍是 FPGA 跨时钟域处理的最基本规范。

**3. 怎么验证它是对的？**
在 Testbench 里看波形，外部信号变化后，经过同步模块，输出应该比输入延迟两个时钟周期才发生变化。如果延迟正好是两个周期，说明同步逻辑正常工作。
