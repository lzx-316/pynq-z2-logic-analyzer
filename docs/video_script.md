# 2~3 分钟演示视频脚本（分镜 + 解说词）

> 建议录制：OBS 或 Windows 自带录屏（Win+G），1080p，先录屏后配音，或用 PPT 演讲者视图计时。
> 总时长目标 2 分 40 秒。

| 时间 | 画面 | 解说词 |
|---|---|---|
| 0:00–0:15 | PPT 封面 | 这是我们做的 PYNQ-Z2 四通道逻辑分析仪：4 通道、1 MSa/s、2048 点环形缓冲，支持三种边沿触发。 |
| 0:15–0:35 | 背景页 | 调试数字电路时，示波器很难同时看多路时序；商用逻辑分析仪贵，而 FPGA 有并行采样能力，所以我们在 PYNQ-Z2 上自己实现了一台。 |
| 0:35–1:00 | 系统架构图 | 采集在 PL 侧：探针先经过 sync_4ch 两级同步，sample_divider 产生 1 MSa/s 的采样使能，capture_engine 写入 BRAM 并判触发；PS 侧用 Jupyter Notebook 通过 AXI 配置和读回。 |
| 1:00–1:25 | 状态迁移图 | capture_engine 是五状态机：等 arm、采集并判触发、补后触发、置位 done、等待 clear。环形缓冲写满回绕，trigger_ptr 记录触发点位置，软件据此还原触发前后 256 点。 |
| 1:25–1:50 | 板卡 Jupyter 七步流程 | 上板后把 bit 和 hwh 放进同一个目录，打开 Notebook v2，按七步执行：加载 Overlay、配置参数、单次采集、读取还原、画波形、导出 CSV、连续十次测试。 |
| 1:50–2:15 | 波形图 + 时序资源页 | 实测 done=1、triggered=1、trigger_ptr=256，有效样本 513 点，CSV 513 行 6 列；连续十次全部通过。时序约束全部满足，最差建立余量 10.552 ns，LUT 占用 3.55%，DRC 0 Error。 |
| 2:15–2:40 | 收尾页 | 仓库里保留了 bit/hwh、Tcl 重建脚本、报告和全部测试证据，换一台机器也能复现。我们的演示到这里，谢谢。 |

## 录制前检查

- 关闭微信、QQ 等弹窗通知，避免录进画面。
- 浏览器只保留 PPT 和 Jupyter 两个窗口，缩放 100%。
- 先读两遍解说词，语速控制在每秒 3~4 个字。
- 波形页停留 3 秒以上，让观众看清四条通道。
